# Chrome Web Store submission kit

Everything needed to publish the Baton extension. The only steps left need the owner's Google account:
a one-time $5 developer registration, then upload. Review usually takes a few days.

## 1. Build the package

```bash
npm run build            # writes extension/baton-extension.zip (manifest v3, version from scripts/build-extension.mjs)
```

Upload that zip at <https://chrome.google.com/webstore/devconsole> → **New item**.
To point the extension at a different server: `BATON_RELAY_URL=https://your-server npm run build`.

## 2. Store listing

**Name** (from the manifest): `Baton: move AI chats between ChatGPT, Claude & Gemini`

**Summary** (132 characters max):
> Continue any ChatGPT, Claude or Gemini chat in another AI, with the prompts, tool outputs and files, and what didn't transfer.

**Category:** Productivity · **Language:** English

**Description:**

```
Switching AIs shouldn't mean starting over.

Baton moves a conversation from ChatGPT, Claude or Gemini into another AI, with everything that matters:
• your prompts, word for word
• the answers, code and files the AI made (rebuilt from the chat, byte for byte where possible)
• tool outputs that share links leave out
• a clear list of anything that couldn't come across, so the next AI doesn't assume it exists

How it works
1. Open a chat and click the Baton button.
2. Pick where to continue: Claude, ChatGPT or Gemini. Baton opens it with the handoff ready, files attached.
3. Or get a link: any AI that can browse can read it, and it expires in 7 days.

Private by default
• Baton reads the chat in your own tab, with the session you're already signed in with.
• Nothing leaves your browser until you choose "Get a link". Tab-to-tab handoffs never touch a server.
• Keys, tokens, emails and phone numbers are redacted automatically.
• No accounts, ads, analytics or tracking. Open source.

Also available without installing anything: a one-click bookmark and a paste box at
https://baton-relay.nimitjain-248.workers.dev
```

## 3. Privacy practices tab

**Single purpose:**
> Move a conversation from one AI chat site (ChatGPT, Claude, Gemini) to another, including its files and a record of what could not be moved.

**Permission justifications:**

| Permission | Why |
|---|---|
| `storage` | Saves the user's settings (server URL, redaction on/off). |
| `unlimitedStorage` | Holds a captured conversation with its generated files (can exceed 5 MB) between the source tab and the target tab during a handoff. |
| Host: `chatgpt.com`, `chat.openai.com`, `claude.ai`, `gemini.google.com` | Shows the Baton button on these sites, reads the open conversation with the user's existing session when they click Capture, and fills the next AI's message box when they continue there. |
| Host: `*.oaiusercontent.com`, `*.openai.com` | Downloads files ChatGPT generated in the conversation (PDFs, code, images) so they move with it. |
| Host: `baton-relay.nimitjain-248.workers.dev` | Stores a handoff when the user clicks "Get a link", and fetches one when they paste a Baton code. |
| Optional host: `https://*/*` | Asked for only if the user configures their own Baton server in Options. |
| Remote code | **No.** All code ships in the package. |

**Data usage disclosures** (what to tick):

- **Website content: Yes.** The conversation the user chooses to capture. It's sent to the Baton server only when they click "Get a link".
- **Personally identifiable information:** not collected by Baton. Conversations may contain it; obvious identifiers are redacted before upload.
- Everything else (health, financial, authentication, location, web history, user activity): **No.**
- Certify: not sold to third parties, not used for unrelated purposes, not used for creditworthiness or lending.

**Privacy policy URL:** <https://baton-relay.nimitjain-248.workers.dev/privacy>

## 4. After approval

- Put the store link on the landing page (`src/site/home.ts`, "For power users" card) and in the README.
- Each release: bump `version` in `scripts/build-extension.mjs`, run `npm run build`, upload the new zip.
